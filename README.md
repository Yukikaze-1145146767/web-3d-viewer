轻量级 Web 3D 查看器

一个基于 Three.js 的轻量级 Web 端 3D 模型查看器。

无需安装专业 3D 软件，只需要浏览器即可加载并查看 ".obj" 模型资源。

支持 OBJ 模型、MTL 材质以及纹理贴图加载，适合快速预览、检查和分享 3D 模型文件。

✨ 特性

- 🌐 纯 Web 实现
  
  - 单 HTML 文件即可运行
  - 无需后端部署
  - 支持本地浏览器运行

- 🧩 OBJ 模型支持
  
  - 加载 ".obj" 文件
  - 支持 ".mtl" 材质文件
  - 支持纹理贴图

- 📦 ZIP 一键加载
  
  - 将模型资源打包为 ZIP
  - 自动解析：
    - ".obj"
    - ".mtl"
    - ".png / .jpg / .webp / .bmp / .tga / .dds" 等纹理

- 🎨 材质与贴图处理
  
  - 自动匹配纹理路径
  - 支持：
    - Diffuse Map ("map_Kd")
    - Bump Map ("map_bump" / "bump")
    - Specular Map ("map_Ks")

- 📱 移动端适配
  
  - 支持触控操作
  - 针对移动设备优化渲染性能

- 🔧 辅助功能
  
  - 自动调整模型视角
  - 模型旋转
  - 视角重置
  - 顶点 / 三角面统计
  - 纹理加载调试日志

🚀 使用方法

1. 打开查看器页面。

2. 准备模型 ZIP 文件：

model.zip

├── model.obj
├── model.mtl
├── texture.png
└── ...

3. 点击「选择 ZIP」。

4. 加载完成后即可在浏览器中查看模型。

🖱️ 操作

操作| 功能
鼠标拖动 / 手指滑动| 旋转模型
滚轮 / 双指缩放| 缩放视角
旋转按钮| 自动旋转
重置按钮| 恢复视角

🛠️ 技术栈

- "Three.js" (https://threejs.org/)
- WebGL
- JavaScript ES Module
- JSZip

📌 当前限制

- 主要针对 OBJ 工作流设计
- 不支持复杂动画
- 大规模高面数模型可能受到浏览器性能限制
- MTL 解析覆盖常见格式，不保证支持所有扩展
